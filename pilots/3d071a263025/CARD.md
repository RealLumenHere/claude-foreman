## Why this is a pilot and not a research prompt

The benchmark addresses a real gap (no eval harness) but its office-suite tasks are not
clearly aligned with Lumen's homelab/orchestration duties; deferring while we evaluate
mapping feasibility avoids wasted effort.

## Hypothesis

An agent using OmegaUse-OfficeVal's verifier-scored docx-formatting tasks as a treatment
(fixing detected rule violations) raises the fixed sample's aggregate
`total_score/max_score` ratio by a clear margin over the unmodified baseline documents,
AND at least one of the sample's flagged rules maps to a Lumen homelab/orchestration
concern (not just office-document typesetting).

## Primary metric

Aggregate compliance ratio `sum(total_score)/sum(max_score)` across the fixed sample,
baseline vs. treatment, per OmegaUse-OfficeVal's own per-rule verifier scoring
(`work/OmegaUse-OfficeVal/verifiers/<task>_verifier.py`, invoked via `work/run_eval.py`).

## Fixed sample

Three tasks from OmegaUse-OfficeVal (commit `ffbeecb8752447c8e40b594a0eeb1db7236ecb36`,
https://github.com/baidu-frontier-research/OmegaUse-OfficeVal), downloaded by
`work/download_tasks.py`: `officeval_002`, `officeval_005`, `officeval_010` — each a
`.docx` thesis/report scored against task-specific header/footer/margin/typography rules.
Both arms run against the same three source files.

## Baseline (measure FIRST)

```
python3 work/run_eval.py <task_id> work/baseline/officeval_<task_id>/
```
Run for all three tasks before any treatment edit (see Results).

## Treatment

The smallest treatment that tests the hypothesis: manually correct the verifier-flagged
violations in each task's `.docx` and re-score. Only task `005` was attempted before the
prior run was KILLED (`work/fix_005_margins.py`, one section-margin fix); `002` and `010`
never received a treatment attempt.

## Kill criteria

- Wall-clock exceeds budget -> stop, report what was measured.
- Treatment cannot be completed for the full fixed sample within budget -> stop, report
  the partial result and what it implies, rather than extrapolating from one task.
- Rules across the sample are dominated by document-typesetting minutiae with no
  plausible mapping to homelab/orchestration work -> stop, this is evidence for SKIP on
  its own regardless of the score delta.
