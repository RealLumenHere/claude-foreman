# Limpet GRUB theme

`theme.txt` is a GRUB2 `gfxmenu` theme in the dark token palette
(`docs/branding-spec.md` §2.1). It is installed to
`/boot/grub/themes/limpet/` by `limpet/iso-builder/build.sh` stage9, which also:

- renders `limpet-logo-128.png` from `../../limpet-logo.svg` via
  `../../export-assets.sh`, and
- sets `GRUB_THEME=/boot/grub/themes/limpet/theme.txt` and
  `GRUB_GFXMODE=1024x768` in `/etc/default/grub`, then runs `update-grub`.

The `select_*.png` / `terminal_box_*.png` slices referenced here are the
standard GRUB pixmap-style nine-slices generated by `export-assets.sh` from the
`primary`/`surface` tokens (a flat rounded rect, no gradients) — GRUB requires
the `*` filename convention for stretchable boxes.

Previously `stage9` shipped a text-mode menu because no graphical theme existed
(`limpet/iso-builder/README.md` "GRUB/Plymouth branding"); this ticket (wq#3948)
supplies it, so the deferral note there is now resolved.
