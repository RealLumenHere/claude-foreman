two benign strings ISSUE-LOG rows 548/554/568 use as the example of the
unanchored-prefix bug. Neither is a credential; both are refused by the
pre-wq#2292 rule and accepted by the anchored one.

- The repo name `highs_solver` reads as a token to an unanchored `ghs_` rule.
- A masked artefact read back, `ghp_MASKED`, re-arms the same alarm because the

worker cannot describe this class of bug without writing the strings down, so a
broker that denies them denies the ticket.
