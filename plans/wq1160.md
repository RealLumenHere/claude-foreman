## Proposed Change

Edit `probe_maat_vault()` in `/home/lumen/sentinel/probes/sentinel_probes.py`
to implement the wq#294 design: probe whichever node `/home/lumen/ha/primary`
names as current primary, not a hardcoded host.

```python
VAULT_ORIGINS = {
    "wadjet": "http://192.168.8.173:8222/alive",
    "maat":   "http://100.105.219.34:8222/alive",
}
HA_PRIMARY_FILE = Path("/home/lumen/ha/primary")

def probe_maat_vault():
    """Vaultwarden /alive on whichever node /home/lumen/ha/primary names as
    current primary (wq#294 design). The standby's VW container is correctly
    stopped -- a probe hardcoded to one host false-CRITICALs forever once the
    other node is promoted (wq#1160 root cause)."""
    try:
        primary = HA_PRIMARY_FILE.read_text().strip()
    except Exception as e:
        return False, f"cannot read {HA_PRIMARY_FILE}: {e}", True
    url = VAULT_ORIGINS.get(primary)
    if not url:
        return False, f"unknown primary '{primary}' in {HA_PRIMARY_FILE} (known: {sorted(VAULT_ORIGINS)})", True
    try:
        t = time.time()
        st, _ = _http(url, timeout=8)
        ms = round((time.time() - t) * 1000)
        if st == 200:
            return True, f"primary={primary} /alive 200 ({ms}ms)", False
        return False, f"primary={primary} /alive HTTP {st}", True
    except Exception as e:
        return False, f"primary={primary} Vaultwarden /alive unreachable: {type(e).__name__}: {str(e)[:80]}", True
```

## Risk Assessment

- **Blast radius:** one function in one probe script, read-only (HTTP GET to
  `/alive` endpoints + a file read of `/home/lumen/ha/primary`). No writes to
  Vaultwarden, Postgres, or HA state anywhere in the new code path.
- **Failure mode if the edit itself is wrong:** worst case is the probe
  throws/misreports and either (a) keeps false-CRITICALing exactly as today
  (no regression), or (b) false-PASSes and silently misses a real Ma'at/Wadjet
  outage for up to one 30-min cycle until Frank or another signal (public
  edge check, `wadjet-ha-monitor`'s own alerting, Gatus ICMP) catches it —
  acceptable because those independent layers still cover a real outage.
- **`unknown primary` case:** if `/home/lumen/ha/primary` ever contains
  anything other than `wadjet`/`maat` (typo, new HA target), the probe now
  fails CRITICAL with an explicit "unknown primary" message instead of
  silently checking the wrong host — a strictly more informative failure
  than today's silent mistargeting.
- **Why acceptable:** this mirrors the already-shipped `_stale_or_none`
  pattern elsewhere in the same file (wq#1092) — narrow, additive,
  read-only, with a one-command file-level rollback. The alternative (do
  nothing) leaves a probe that will CRITICAL-page every 30 minutes forever
  as long as Wadjet remains primary, which is worse.
