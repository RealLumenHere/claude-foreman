# BIN_TOOL_AUDIT — /home/lumen/bin tool-documentation audit (wq#1579)

_Generated by an automated header/--help scan of every executable in /home/lumen/bin, cross-referenced against minerva/context/fleet_tools.yaml (the FLEET_TOOLS.md source of truth). 295 executables total: 167 live tools + 128 `.bak`/`.retired`/`.staged`/`.new` variants._

## Method
- A tool counts as **documented** if it has a `"""docstring"""` / ≥2-line leading comment block, OR implements `--help`/argparse/getopts/a `usage:` string.
- 7 of 167 live tools had **neither** — those get a full paragraph below (read from source), same as the task asked. Two vendored third-party binaries (`gatus`, `trivy`) also scanned as undocumented since they're compiled Go binaries with no fleet-side header — included for completeness with their own `--help` noted as the real doc.
- `.bak`/`.retired`/`.staged`/`.new` files are backups/superseded copies by convention (see HANDOFF change-safety pattern) — flagged dead unless a live script or systemd unit references that exact filename.
